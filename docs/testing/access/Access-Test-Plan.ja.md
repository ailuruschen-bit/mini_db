# アクセスモジュール テスト計画

> 言語: [English](Access-Test-Plan.md) | **日本語**

`internal/access` モジュール — バッファプールの上でページをタプルに変えるアクセスメソッドのテスト計画。現在は `heap` パッケージ（ヒープファイルのアクセスメソッド）; B-tree インデックスメソッドは後で加わる。*どう書くか*（フレームワーク、`-race`、カバレッジ）は [テスト規約](../Test-Conventions.ja.md) にあり、本書はコンポーネントごとに *何をカバーするか* を列挙する。

---

## 0. 共有ヘルパー（heap）

- `newHeap(poolSize)` — 一時ディレクトリの実バッファプール + ディスクファイル上のヒープ。
- `payload(seed, size)` — 指定サイズの、区別・検証可能なタプル。
- `initPage()` — フェイク状態を組むための整形済み空ページ。
- `fakePool` — heap が依存する消費者側インタフェース `pager` を実装し、`FetchPage`/`NewPage` をオンデマンドで失敗させる。heap の I/O エラー経路を決定論的に駆動するため。

---

## 1. Heap（`heap_test.go`、ブラックボックス `heap_test`）

`TID = {Page, Slot}` はタプルの物理アドレス。v1 の操作: Insert / Get / Scan（削除・更新は MVCC/トランザクション層待ち）。タプルのバイトは heap にとって不透明。

- [x] **往復:** Insert 後に Get が同じバイトを返す。
- [x] **ページをまたぐ:** 十分大きいタプルが新しいページへあふれ、そのすべてが id で読み戻せる。
- [x] **Scan:** すべてのタプルをちょうど一度ずつ、ページをまたぎ、追い出しを通して（プールがページ数より小さい）訪れる。
- [x] **Scan の早期停止:** コールバックのエラーがスキャンを中断し、外へ伝播する。
- [x] **Get の境界:** 範囲外スロットを拒否; 存在しないページを拒否。
- [x] **大きすぎる Insert:** 空ページに収まらないタプルは、落とさず拒否する。
- [x] **永続化:** タプル id はクローズ/再オープンをまたいで有効（再オープン後に古い TID で Get できる）。
- [x] **エラー伝播（`fakePool`）:** Insert は `FetchPage` 失敗と `NewPage` 失敗を表面化する; Insert は想定外の（`ErrNoSpace` でない）ページエラーを「ページ満杯」と誤らず伝播する; Scan は `FetchPage` 失敗を表面化する。

---

## 実施順序

1. スキャフォールド: テストファイル、ヘルパー、`fakePool`。
2. Insert/Get の往復、次にページまたぎ。
3. Scan — 全訪問、次に早期停止。
4. エラー経路 — 実物（範囲外・大きすぎ・再オープン）とフェイク注入（fetch/new/想定外）。
5. 仕上げ: `make check`（vet + lint + race + カバレッジ）、`feat(heap): ...` でコミット。
